Transfer Function H(s) Derivation

$$H(s) = X_s(s)/Z_r(s) = (c_s\cdot s + k_s) / (m_s\cdot s^2 + c_s\cdot s + k_s)$$

INTUITION

왜 이 수식이 필요한가?

💡 수식 유도 읽는 법 — 각 STEP의 파란색 라벨은 "왜 이 변환을 하는가"를 설명합니다. 수식만 보지 말고 동기 $\rightarrow$ 변환 $\rightarrow$ 의미 순서로 읽으세요. 눈으로 3번 읽는 것보다 손으로 1번 쓰는 것이 기억에 4배 효과적입니다.

Day 05~06에서 '진폭비와 위상각'을 배웠는데, 이를 일반화한 것이 전달함수입니다. 라플라스 변환(s=$\sigma$+j$\omega$)을 사용하면 미분방정식이 대수 방정식이 되어 다루기 쉬워집니다. 차량 NVH에서 전달함수는 '노면 $\rightarrow$ 차체' 경로의 진동 특성을 완전히 기술하는 도구입니다. Simpack의 FRA(Frequency Response Analysis)가 바로 전달함수를 수치적으로 구하는 것.

DERIVATION

수식 한 줄씩 유도

STEP 1 — 라플라스 변환 적용
$$m_s\cdot s^2X_s + c_s\cdot s(X_s-X_u) + k_s(X_s-X_u) = 0$$

이 항의 의미: 시간 미분 x'' $\rightarrow$ s²X(s), x' $\rightarrow$ sX(s). 초기조건=0 가정(정상상태 분석). 대문자 $X_s$(s), $X_u$(s)는 라플라스 변환된 변위.

부호/변환 이유: s는 복소 주파수. s=j$\omega$ 를 대입하면 Day 05의 주파수 응답과 동일. 라플라스는 더 일반적.

이전 단계와의 연결: Day 08의 시간영역 방정식을 주파수(s)영역으로 변환한 것.

↓
STEP 2 — 단순화: 타이어 강체 가정
$$\begin{aligned} X_u \approx Z_r (k_t \rightarrow \infty \text{근사}) \\ \rightarrow m_s\cdot s^2X_s + c_s\cdot s(X_s-Z_r) + k_s(X_s-Z_r) = 0 \end{aligned}$$

이 항의 의미: 타이어가 매우 딱딱하면($k_t$$\gg$ $k_s$) 휠이 노면을 그대로 추종. 쿼터카가 1DOF로 축소. 기본 전달함수 유도에 적합.

부호/변환 이유: 이 근사는 바디 바운스 주파수 영역(약 1 Hz)에서 유효. 휠 홉 영역(약 12 Hz)에서는 부정확.

이전 단계와의 연결: Day 09의 $m_u$$\rightarrow$0 극한과 동일한 단순화. 2DOF$\rightarrow$1DOF 축소.

↓
STEP 3 — 전달함수 도출
$$H(s) = X_s/Z_r = (c_s\cdot s + k_s) / (m_s\cdot s^2 + c_s\cdot s + k_s)$$

이 항의 의미: $X_s$에 대해 정리하면 전달함수. 분자: 입력(노면)이 스프링·댐퍼를 통해 전달. 분모: 시스템 동특성(관성+감쇠+강성).

부호/변환 이유: s=j$\omega$ 대입: |H(j$\omega$)| = Day 05의 진폭비와 관계. 분모=0이 되는 s값이 극점(pole) $\rightarrow$ 고유진동수 결정.

이전 단계와의 연결: Day 05의 X/$X_{st}$를 전달함수 형태로 다시 표현한 것. s 도메인이 더 범용적.

📐 상세 유도과정 (Step-by-Step)

중간 과정 완전 전개

① 운동방정식의 라플라스 변환

$$m\ddot{x} + c\dot{x} + kx = F(t) \xrightarrow{\mathcal{L}} ms^2X(s) + csX(s) + kX(s) = F(s)$$
$$X(s)(ms^2 + cs + k) = F(s)$$

변환 이유: 미분방정식 $\rightarrow$ 대수방정식으로 변환. 초기조건 = 0 가정 (강제응답만 관심)

② 전달함수 H(s) 도출

$$H(s) = \frac{X(s)}{F(s)} = \frac{1}{ms^2 + cs + k} = \frac{1/m}{s^2 + 2\zeta\omega_n s + \omega_n^2}$$

표준형: 분모의 계수에서 $\omega_n = \sqrt{k/m}$, $\zeta$ = c/(2$\sqrt{mk}$) 직접 읽기 가능

③ 주파수응답함수: s = j$\omega$ 대입

$$H(j\omega) = \frac{1/m}{(j\omega)^2 + 2\zeta\omega_n(j\omega) + \omega_n^2} = \frac{1/m}{(\omega_n^2 - \omega^2) + j(2\zeta\omega_n\omega)}$$
$$|H(j\omega)| = \frac{1/m}{\sqrt{(\omega_n^2-\omega^2)^2 + (2\zeta\omega_n\omega)^2}}$$

크기(Magnitude)는 진폭비, 위상(Phase)은 arctan(허수/실수). 보드 플롯: |H|을 dB로, Phase를 degree로 표시

④ 보드 플롯의 3구간 해석

$$\text{저주파 } (\omega \ll \omega_n): |H| \approx \frac{1}{k} = \frac{1}{\omega_n^2 m} \quad (\text{정적 강성 지배})$$
$$\text{공진 } (\omega = \omega_n): |H| \approx \frac{1}{2\zeta\omega_n^2 m} = \frac{Q}{k} \quad (\text{감쇠만 지배})$$
$$\text{고주파 } (\omega \gg \omega_n): |H| \approx \frac{1}{m\omega^2} \quad (\text{관성 지배, }-40\text{dB/dec 감쇠})$$

설계 인사이트: 고주파 절연은 질량↑(무거울수록 좋음), 공진 억제는 $\zeta$↑(감쇠↑). 서스펜션은 이 둘의 트레이드오프!

DEEP DIVE

심화 학습

전달함수 H(s)의 본질은 분모=0의 근(극점, poles)과 분자=0의 근(영점, zeros)으로 결정됩니다.

전달함수: $H(s) = \frac{N(s)}{D(s)} = \frac{\prod(s - z_i)}{\prod(s - p_j)} \rightarrow$ 영점 $z_i$, 극점 $p_j$

2차 시스템 극점: $p = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2}$

극점(Poles): 분모 $m_s$·s²+$c_s$·s+$k_s = 0$ 의 근 $\rightarrow$ s = −$\zeta \omega_n$ $\pm$ j$\omega_d$ (Day 04와 동일!) $\rightarrow$ 극점의 실수부 = 감쇠, 허수부 = 진동 주파수

영점(Zeros): 분자 $c_s$·s+$k_s = 0$ 의 근 $\rightarrow$ s = −$k_s$/$c_s$ $\rightarrow$ 이 주파수에서 전달이 0 (완전 차단)

Bode Plot 읽기: · 극점 주파수 근처: 공진 피크 · 영점 주파수 근처: 반공진(dip) · 고주파($\omega \gg \omega_n$): s² 지배 $\rightarrow$ −40 dB/decade 감쇠

Day 13에서 이를 '전달률(Transmissibility)' 개념으로 발전시킵니다.

■ 극점 (Poles) — 분모 = 0의 근

극점 실수부 $= -\zeta\omega_n$: 감쇠 속도 결정  |  허수부 $= \omega_d$: 진동 주파수 결정

영점: $H(z_i) = 0 \rightarrow$ 해당 주파수에서 전달이 차단됨 (anti-resonance)

시스템의 고유 특성을 결정: s = −$\sigma \pm$ j$\omega_d$

$\sigma$ = $\zeta \omega_n$: 감쇠 속도 ($\sigma$ 클수록 빨리 감쇠)

$\omega_d$ = $\omega_n\sqrt{1-\zeta^2}$: 감쇠 진동 주파수

■ 영점 (Zeros) — 분자 = 0의 근

특정 주파수에서 출력이 0 $\rightarrow$ "anti-resonance"

쿼터카 H(s)에서 영점: s = −$k_s$/$c_s$ $\rightarrow$ 실수축 위의 점

■ Simpack에서 확인

FRA 결과의 magnitude plot에서 극점 = peak, 영점 = dip으로 나타남

■ Magnitude Plot (크기)

바디 전달률: $T_{body}(\omega) = \frac{X_s}{X_r} = \frac{k_s + j\omega c}{k_s + k_t - m_s\omega^2 + j\omega c}$

$|T_{body}| < 1$ (방진 영역): $\omega > \omega_n\sqrt{2} \rightarrow f > f_n\sqrt{2}$

르노코리아 실무 Tip: Simpack에서 Sine Sweep 가진 후 바디 가속도/노면 변위로 FRF를 구합니다. Bode Plot 기울기가 -40 dB/dec인지 확인하세요.

|H(j$\omega$)| > 1 (0 dB 이상): 진동 증폭 영역 $\rightarrow$ 승차감 악화

|H(j$\omega$)| < 1 (0 dB 이하): 진동 절연 영역 → 서스펜션이 일하는 영역!

피크 높이 = Q-factor $\approx$ 1/(2$\zeta$): 감쇠가 작을수록 피크가 높음

■ Phase Plot (위상)

0° 근처: 입출력이 동위상 $\rightarrow$ 차체가 노면을 그대로 추종

−90°: 공진 부근 $\rightarrow$ 에너지가 가장 많이 흡수되는 지점

−180° 접근: 입출력 역위상 $\rightarrow$ 차체가 노면과 반대로 움직임 (고주파)

■ 레퍼런스 차량 타겟

body bounce peak < 3 dB (|H| < 1.4), 절연 시작점 < 2 Hz
