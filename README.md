# 샤시 퀘스트

실무 경험을 차량동역학 이론과 설계 판단으로 연결하는 하루 10분 학습 게임입니다. GitHub Pages에서 공개하며, ChatGPT나 GitHub 로그인 없이 누구나 이용할 수 있습니다.

## 학습하기

**[샤시 퀘스트 시작하기](https://dahliarising.github.io/chassis-quest/)**

- 진동, 서스펜션, 조향, 제동, 차량 통합을 다루는 60강과 10개 학습 구간
- 실무 판단 문제, 설명 연습, 원문 퀴즈, 오답 복습과 체크포인트
- 객관식 149문항의 보기별 해설: 오답 이유, 필요한 정의, 풀이 접근법을 즉시 확인
- XP, 연속 학습일, 배지와 10개 장면의 차량 실험실
- 해설에서 바로 조작하는 차량 그림: 출렁임·방지턱·공진·저속 조향·제동·롤
- 매개변수 → 수치 대입식 → 차량 움직임 → 그래프를 함께 비교하고, 재생·정지·시간 이동으로 관찰
- 기준값과 변경값의 차량을 같은 시간·같은 축척으로 나란히 재생하고, 두 응답 그래프를 겹쳐 비교
- 바뀐 변수, 그대로인 결과, 달라진 이유를 그림 옆에서 즉시 확인
- **먼저 맞혀보기**: 값을 바꾼 뒤 결과를 예상하고, 답을 고르면 전후 애니메이션과 즉시 해설로 확인
- 10개 장면의 추천 조건 20개와 직접 바꾼 조건으로 풀 수 있는 예측 문제
- **예측 오답 정비소**: 틀린 조건을 그대로 다시 풀고 정비 완료 여부를 확인
- **개념별 예측 기록**: 서로 다른 조건의 첫 오답률·총 오답·재도전·정비 대기를 구분
- **샤시 딥다이브**: 하드포인트 기구학, K&C 토·캠버, 킹핀·캐스터·스크럽·트레일, 코너링·조향 이론과 실습
- 심화 용어 16개·이론 20개·실습 8개. 교육용 모델의 범위와 부호·단위를 명시하며 코너링 범위 초과 시 예측 채점 중단
- 채점에 반응하는 스프링 정비사와 구간별 샤시 유머
- [원문 강의 목록](lecture/index.html)과 [콘텐츠 검토 기록](data/source-report.json)

## 3D 포뮬러 테스트 캠프

흰색·파랑 차체, 버블 캐노피, 대형 윙과 트윈 부스터를 가진 미래형 레이싱 머신으로 밝은 서킷과 피트를 달립니다. PC는 WASD·방향키, Space 제동, Shift 부스터, E 실습이며 휴대폰은 화면 버튼으로 조작합니다. 부스터는 도로 위 전진에서 최대 3초 사용하고 완전히 소진하면 6초 충전 후 다시 사용할 수 있습니다. 지도에서 네 장소로 바로 이동할 수도 있습니다. 피트 교신은 주행 상태에 따라 바뀌는 안내 문구입니다.

**첫 테스트 시작**에서는 타이어 변경 → 움직임 예상 → 두 차 동시 주행 → 앞바퀴 조향각 조정 → 재시승을 진행합니다. 기준 반경의 3% 이내로 들어오면 배지를 받습니다. 예측 오답은 정비소에 저장됩니다. 완결된 현장 임무는 코너링 1개이며 라이드 로드·지오메트리 랩·정비동은 기존 실험과 복습으로 연결합니다.

자유 주행은 탐색용이고 임무는 교육용 선형 모델의 정상 선회 결과입니다. 차량 표시 크기는 확대했습니다. [모델 식과 범위](PHYSICS.md)를 확인하세요. WebGL을 사용할 수 없으면 동일 임무를 2D로 진행합니다. Three.js 0.186.1은 저장소에 포함되며 [MIT 라이선스](vendor/THREE-LICENSE.txt)를 따릅니다.

## 학습 기록과 이전 사이트에서 이동

진도는 사용 중인 브라우저에 저장되며 계정이나 서버로 자동 동기화되지 않습니다.

1. 이전 사이트의 **성장 기록 → 학습 기록 백업**에서 JSON 파일을 저장합니다.
2. 이 사이트의 **성장 기록 → 백업 불러오기**에서 파일을 선택합니다.
3. XP와 학습 완료 기록을 확인합니다. 다른 기기나 브라우저로 옮길 때도 같은 방법을 사용합니다.

백업 파일에는 개인 학습 기록이 있으므로 공개 저장소에 올리지 마세요.

## 실행과 배포

HTML·CSS·JavaScript로 만든 정적 사이트입니다. 별도 빌드나 서버 비밀키가 필요 없습니다. GitHub Pages의 배포 소스를 저장소 기본 브랜치의 루트 폴더로 설정합니다. 프로젝트 하위 경로에서도 강의 링크가 작동하도록 상대경로를 사용합니다.

수식 표시와 글꼴은 강의 원문의 외부 CDN을 사용합니다. 원문 퀴즈의 일부 오류는 게임 문항에서 제외했으며, 원문 강의 전체의 기술 검증이 완료되었다는 뜻은 아닙니다.

오답 코칭은 `data/coaching-early.js`와 `data/coaching-late.js`에서 관리합니다. 보기별 해설은 화면에 섞여 보이는 순서가 아닌 원래 선택지 인덱스에 연결합니다. 일부 질문은 힘 가진·선형 근사 등 적용 조건을 명시하도록 표현을 보완했습니다. 움직임은 학습자의 입력에 반응하며, 기기의 동작 줄이기 설정에서는 진동 실험을 시간별 정지 화면으로 확인할 수 있습니다.

시각 해설은 `physics.js`에서 계산하고 `visual-explainer.js/css`에서 표시합니다. `data/visual-guides.js`는 강의별 관찰 포인트를 연결합니다. [모델 식과 가정](PHYSICS.md)을 확인할 수 있습니다. 실차 계측으로 보정한 예측기가 아닌 교육용 모델이며, 계산하지 않는 기구학·타이어·제어 주제는 해당 실험 안내에 명시합니다.

전후 비교에서는 왼쪽 기준이 고정된 상태로 오른쪽 값을 조절합니다. **현재 값을 기준으로**를 누르면 새 비교의 출발점이 됩니다. **변경 취소**는 기준값으로, **오른쪽 기본값**은 해당 장면의 초기값으로 되돌립니다. 한쪽 계산이 먼저 끝나면 마지막 장면을 유지하며, 시간 슬라이더는 두 차량을 같은 시각으로 이동합니다. 여러 값을 함께 바꾸면 각 변수의 영향과 실제로 합쳐진 계산 결과를 구분해서 설명합니다. 비교 상태는 해당 화면에서만 유지하며 학습 기록이나 XP를 바꾸지 않습니다. 비교 해설은 `comparison.js`에서 관리합니다.

예측 퀴즈는 해설이나 실험실에서 **먼저 맞혀보기**를 누르면 시작합니다. 답변 전에는 차량 움직임·계산 결과·그래프를 가리고, 답을 고르면 내 예상과 실제 방향 및 핵심 이유를 표시한 뒤 두 차량을 함께 재생합니다. **다른 조건 퀴즈**로 추천 문제를 바꾸거나 슬라이더를 직접 조절해 새 예측을 할 수 있습니다. 조건이 바뀌면 이전 채점은 지워집니다. 동작 줄이기 환경에서는 자동 재생 없이 시간 슬라이더로 확인합니다. 연습 결과는 학습 XP나 진도에 더하지 않습니다. 문제 생성과 채점은 `prediction.js`에서 현재 물리 모델의 지표를 비교해 처리합니다.
